# Verification and publication checklist

- [ ] Identify original model author(s), source and any third-party content (including the PIRC logo).
- [ ] Obtain permission to distribute the `.slx` and `.fis` files.
- [ ] Record the UTS unit, semester/year and group members' contributions.
- [ ] Open and simulate the model in MATLAB; document required toolboxes.
- [ ] Save reproducible, verified results with MATLAB version, solver and settings.
- [ ] Cite external models, diagrams, fuzzy rules and other material.
- [ ] Select a licence only after confirming ownership and reuse rights.

**Do not publish the supplied model binaries until these checks are completed.**
